# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's **Report a vulnerability** feature on this repository's **Security** tab. Do not open a public issue containing credentials, access tokens, private Trello data, or an exploitable vulnerability.

If private vulnerability reporting is unavailable, contact the repository maintainer through the contact details on the GitHub profile [@Mufid2225](https://github.com/Mufid2225). Please include a description of the issue and steps to reproduce it, but never include live credentials or private user data.

## Scope

This project is a local AI agent skill and Python helper for Trello's REST API. Reports about credential handling, unintended mutations, permanent deletion, or exposure of Trello data are especially relevant.
